# 生命进化 · Life Evolution

一款 iOS 放置点击进化游戏：从一颗原始细胞一路进化到「终焉之外」，在 60 个形态之间靠点击、产线、飞升、变异、遗物和时代事件层层推进。

纯 Objective-C + UIKit 手写，用 [Theos](https://theos.dev) 交叉编译成 **未签名 ipa**，装到手机上需要自行签一次名（TrollStore 或 AltStore / Sideloadly）。

> 单机离线游戏，没有任何联网、内购、广告或统计 SDK。存档只存在本机 `NSUserDefaults`。

## 核心循环

```
点击 / 自动产出攒能量
      ↓
买产线 → 产出变快 → 解锁更多产线
      ↓
攒够进化费用 → 进入下一形态（形态决定主题色、背景、配乐、产线外观）
      ↓
每 6 级遇到一次守关者 → 40 秒内点破；每关每轮回只有 2 次挑战机会，两次失败即封锁，需飞升重开轮回才能继续进化
      ↓
能量攒到门槛 → 飞升：清空进度换 DNA，难度与产出同步缩放
      ↓
DNA 投入基因组强化（永久，飞升保留）+ 遗物（永久）
      ↓
重复，直到第 60 个形态「万有归一」
```

## 产线与购买

- 每个形态有若干条产线，单价与产出按 `15 × 5^i` / `0.1 × 5^i` 逐级放大，成本增长率固定 **1.17**
- 支持 **1 / 10 / 100 / 最大** 四种购买批量，「最大」会算出当前能量真正买得起的数量（严格按同一增长率扣费，不会出现扣款超额）
- 每行显示：单产、持有数量、整卡进度条、「现可买 ×N」
- **★ 最优** 标记：按「每单位能量的产出增量」实时推荐最划算的一条，节流 0.4 秒刷新
- **里程碑**：单条产线持有量达到 10 / 25 / 50 / … / 66000 等 20 个档位，每一档产出直接 ×2，行内进度条提示下一档

## 点击、连击与暴击

- 点击收益 `0.1 + 总产出 × 5%`，再叠乘连击、变异与遗物加成
- 连击 1.5 秒内不断点击累积，每层 +0.1 倍率（「节奏大师」变异改为 +0.14），上限随变异提升
- 暴击：命中时 3 倍收益，飘红字、震感更重；「猎手直觉」「连锁暴击」提高概率，「暴击回响」有 25% 概率追加一次等额收益
- 每次有效点击都有 Core Haptics 震动（轻点 / 暴击 / 连击加成分别用不同强度），并有涟漪、粒子、数字飘字、生物弹跳反馈

## 进化：60 个形态

细菌 → 藻类 → 海绵 → 水母 → 小鱼 → … → 太一 → 归零者 → 终焉之外。

- 每个形态有独立名称、副标题（地质年代）、主题色、emoji 主体、背景全景与配乐
- 进化费用从 1 级到 60 级跨度约 `7.5e28 → 1.2e54`（含 3 倍难度系数与基因税），难度随飞升次数继续放大
- 进化后主题色、背景图、配乐做交叉淡化过渡

## 飞升与 DNA

- 门槛：首次 `20,000,000`；此后每次按 `×20` 递增（第 2 次 4e8、第 3 次 8e9、第 4 次 1.6e11 …），再乘以「基因税」（`1.05^DNA 强化总等级`，上限 60×），进度条实时显示还差多少
- 收益：`sqrt(本轮收益 / 门槛)` 向下取整，再乘「飞升红利」基因与「升维密钥」遗物
- 代价：能量、产线、当前形态全部重置，DNA 与基因组强化、遗物、图鉴、成就永久保留
- 难度缩放：产出 `×0.85^n`（最低 25%）、成本 `×1.22^n`、进化费 `×1.30^n`
- 每次飞升给 **+2 遗物点**

## 基因树（9 节点）

用 DNA 逐点投入，等级**没有上限**，单价按 `1.10^等级` 上涨，飞升后保留。基因页已改为**技能树**：每点一次节点 +1 级，需先点亮前置节点（Lv.1 起）才能解锁下一层，未解锁的节点显示「🔒 需「xxx」Lv.1」。顶部胶囊实时显示可用 DNA。

树状连线（自上而下）：

```
            🧬 基因强化 Lv.0
           /                 \
   👆 点击强化            🤖 自动触手
        |                      |
   ⏳ 离线收益           ✨ 孢子亲和
        |                      |
   ⚔️ 试炼锋芒           🌠 孢子之频
        |                      |
   🕊 飞升红利           🌱 起始遗泽
```

| 强化 | 效果（每级） |
| --- | --- |
| ⏳ 离线收益 | 返还率 +10%（最高 100%），返还时长上限 +1 小时（最高 24 小时） |
| （根节点） | 🧬 基因强化是唯一无需前置的节点 |
| 🧬 基因强化 | 全产出 +50% |
| 👆 点击强化 | 点击收益 +30% |
| ✨ 孢子亲和 | 孢子增益强度 +40% |
| 🤖 自动触手 | 每秒自动点击 1 次（不计连击），生物旁显示「🤖 +收益」 |
| 🕊 飞升红利 | 飞升获得的 DNA +20% |
| 🌱 起始遗泽 | 飞升后每条产线自带等级（每 2 级 +1，最高 300 级） |
| 🌠 孢子之频 | 孢子出现间隔 −10%（最低压到 10%） |
| ⚔️ 试炼锋芒 | 对守关者伤害 +35%／级（锁关时的唯一破局手段） |

## 变异（11 种，三选一）

**每次进化后**弹出三个随机变异供选一，可叠层，本轮有效，飞升或重置后清空。

| 变异 | 效果 |
| --- | --- |
| 👆 掠食强化 | 点击收益 +30% |
| 💧 高效代谢 | 自动产出 +20% |
| 🎯 猎手直觉 | 点击 15% 概率暴击 3 倍 |
| ⏳ 节奏掌控 | 连击保持时间 +1 秒 |
| 🌀 群体共鸣 | 连击上限 +1 |
| ✨ 孢子狂喜 | 孢子增益强度 +80% |
| 🎇 连锁暴击 | 暴击概率 +10% |
| 🌧 孢子雨 | 点击时 6% 概率额外获得一份孢子收益（每层 +6%，上限 24%） |
| 🎼 节奏大师 | 连击每层加成 +0.1 → +0.14 |
| ♨️ 进化余温 | 进化后 15 秒内产出 ×1.4 |
| 🔗 暴击回响 | 暴击时 25% 概率追加一次等额点击收益 |

另有随机出现的 **金色孢子**（每 8 秒消失）。点中后随机触发三种效果之一，强度受「孢子亲和」「孢子王冠」「孢子狂喜」加成：

- **孢子·涌动**：接下来 20 秒产出 ×3
- **孢子·爆发**：接下来 12 秒产出 ×10
- **孢子·时间跃迁**：直接获得接下来 8 分钟（480 秒）的产出

点中孢子时屏幕中部会弹出金色大卡片，显示效果名、倍率与时长；限时增益生效期间右上角常驻金色胶囊 `✨ ×N N.Ns`，实时倒计时。

## 图鉴：60 条形态档案

- 独立标签页，每个形态一条：emoji、名称、时代、设定文本
- 未解锁的显示锁定态；解锁过的按历史最高形态永久记录
- **每解锁一个形态，全产出永久 +2%**（最高 +96%）

## 转生：遗物与成就

遗物点来自飞升（+2）与成就奖励，永久生效，飞升不清空。遗物改为**可逐级加点**：每件最多 Lv.20，第 n 级价格 = 基础价 × 1.75^n。

| 遗物 | 效果 | 价格 |
| --- | --- | --- |
| 🌊 潮汐之心 | 全产出 +15%／级 | 1 |
| 🦴 掠食之爪 | 点击收益 +20% | 1 |
| 👑 孢子王冠 | 孢子增益强度 +30%／级 | 2 |
| 🔑 升维密钥 | 飞升获得 DNA +10% | 2 |
| 🪨 起源遗骸 | 飞升后每条产线额外 +5 级 | 3 |
| 🌫 静默之幕 | 时代事件持续时间 −25% | 2 |

8 项成就（各奖励 1–2 遗物点）：初次触摸（点击 500 次）、完美连击（连击 100 层）、深海远航（解锁 12 形态）、进化狂潮（飞升 3 次）、守关者（击败 3 个守关者）、物种帝国（单产线 200 个）、恒星之火（能量破 1e30）、变异之海（变异累计 100 层）。

## 守关者试炼

- 第 6 / 12 / 18 / 24 / 30 / 36 / 42 级进化前必须通过
- 40 秒内把守关者点破：血量按“需要点多少次”定，第 6 关约 220 次、第 42 关约 700 次（连击会放大每次伤害，实际更快）
- 进化按钮此时变成红色「⚔️ 试炼 · 形态名」，破关后才能正常进化
- 胜利给 DNA 奖励，失败可重来；已通过的关卡永久记录

## 时代事件

负面概率随压力 42%→84%，冷却 150 秒→48 秒，强度与解除代价（`产出×20`，再乘 `1+0.45×压力`）同步上升。

| 事件 | 效果 |
| --- | --- |
| ☄️ 陨石撞击 | 产出 0.50→0.12（随压力下降） |
| 🌋 寒武爆发 | 产出 ×2（正面） |
| 💥 超新星 | 瞬间获得约 900 秒产出（正面） |
| 🕳 熵坍缩 | 成本 ×1.35→×2.07 |
| 🌞 日冕风暴 | 产出 0.45→0.10（随压力下降） |
| 🧬 基因崩解 | 成本 ×1.55→×2.45 |


游戏进行约 80 秒后，每 130–150 秒随机触发一次，屏幕顶部的横幅会显示图标、名称、效果、倒计时和进度条：

| 事件 | 效果 |
| --- | --- |
| ☄️ 陨石撞击 | 产出 −50%，持续 25 秒（橙红流星 + 强震屏） |
| 🦠 寒武纪大爆发 | 产出 ×2，持续 18 秒（绿色双冲击波 + 粒子雨） |
| 💥 超新星爆发 | 立刻获得 900 秒的产出（白金色冲击波 + 全屏闪） |
| 🌀 熵坍缩 | 成本 +35%，持续 20 秒（紫色扫描带 + 暗闪） |

事件期间每 2 秒一次环境粒子，配低频轰鸣音效。

陨石撞击的表现是一整块直径约屏幕 2/3 的巨岩带火焰拖尾从右上角砸进屏幕，落地瞬间白橙爆闪、三波冲击波、80 粒碎片与连续四次余震。

**负面事件可解除**：陨石撞击与熵坍缩期间，屏幕底部会出现红色「🛡 解除」条，消耗 `当前总产出 20 秒` 的能量即可立刻结束该事件（能量不足时按钮变暗并提示还差多少），解除后环境恢复。

## 音画与手感

- **10 首程序化配乐**（每首 8 分钟，按地质时代划分，随形态交叉淡化切换），可一键开关，开关有提示与状态变化
- **8 张 4K 时代全景**，随形态交叉淡化，带暗角与压暗层保证文字可读
- 极光、粒子、涟漪、冲击波、震屏、闪屏等全套反馈
- 界面刷新走 120Hz（`CADisplayLink` + `CADisableMinimumFrameDurationOnPhone`），能量大数字用逐位滚动组件平滑变化
- 数字支持 K / M / B / T / Qa / Qi / … / Nod 后缀与中文缩写，不会出现上百位原始数字

## 离线收益与存档

- 离线按时长 × 总产出 × 返还率结算，需离线 ≥15 秒；上限 8 小时起，随「离线收益」强化每级 +1 小时（最高 24）
- 进入后台和每 5 秒自动存档；读档时会纠正负数、NaN 等异常值
- 「重置存档」清空全部进度

## 数值与显示

- 产线：产出 `0.08 × 5^i`，成本 `18 × 5^i`，成本增长 1.18
- 批量成本：`Base × 1.17^持有 × (1.17^k − 1) / 0.17`
- 里程碑：20 档（10 / 25 / 50 / … / 66000），每档 ×2
- 加成链：产线 × 基因 × 变异 × 难度 × 进化余温 × 图鉴 × 遗物 × 事件

## 构建与安装

环境：Theos + iOS SDK 16.5 + iPhoneOS 交叉工具链（arm64，最低 iOS 14.0）。

```bash
export THEOS=/path/to/theos
make
make package FINALPACKAGE=1 PACKAGE_FORMAT=ipa
```

产物 `packages/com.demo.lifeevolution_<version>.ipa`。

ipa 未签名：TrollStore 可直接装；或用 AltStore / Sideloadly 以自己的 Apple ID 重签（免费证书 7 天需重签一次）。
